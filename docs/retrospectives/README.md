# Retrospectives

One dated file per change set, audit, or incident, named
`YYYY-MM-DD-<topic>.md`. Each records what happened, what was resolved, what
remains open (by roadmap item id), and a mechanism label from
`AI-ORCHESTRATION.md#the-mechanism-taxonomy` for every defect. The practice
that produces these files is described in
`docs/AI-REVIEW-AND-RETROSPECTIVES.md`.

Retrospectives are history: they are annotated, never rewritten.
